# TenderAssist: getting started

For a new office using TenderAssist for the first time. About 20 minutes, once.

## What you need

- A Windows 10 or 11 computer with internet.
- Your **TenderAssist key** (TA-XXXXX-XXXXX-XXXXX-XXXXX), sent to you by message or email.
- A **Google account** for the office. The key is linked to it, and approved tenders are saved in its Google Drive.
- For Tamil Nadu and other GePNIC websites: the website's **login ID and password**, and your **DSC token** with its PIN. GeM needs none of these.

## 1. Install

1. Run `TenderAssist-Setup-x.y.z.exe`.
   - If Windows says "Windows protected your PC", choose **More info → Run anyway**. This goes away once the installer is signed.
2. **Licence agreement:** read it, choose **I accept the agreement**, then **Next**.
3. Choose where to install (the suggested place is fine), then **Next**.
4. **Activation key:** paste your key, then **Next**. Setup checks it straight away.
5. **DSC signer (optional):** shown only when this computer lacks OpenWebStart or Java.
   - Tick it if you will search Tamil Nadu or another GePNIC website.
   - Leave it unticked for GeM only. You can install it later from Settings.
6. **Install**, then **Finish**.

## 2. Activate (first start)

1. TenderAssist opens on **Activate TenderAssist** with your key filled in. Select **Continue with Google**.
2. Your browser opens. Choose the office Google account, **leave the Google Drive box ticked**, and select **Continue**.
3. When the page says "Signed in", go back to TenderAssist.

### Another computer for the same office

Your key covers a set number of computers (for example 3). On the next computer, install TenderAssist and **leave the key empty** (in setup and on the Activate screen), then select **Continue with Google** and sign in with the **same Google account**. That computer is counted as the next one (2 of 3). Reinstalling on a computer already counted does not count again. When all are used, setup says so: ask for another computer to be added.

## 3. The setup checklist (on Today)

Today shows **Get set up** with every one-time step. Select the **(i)** beside any step to see what it is for. Steps marked "ticks itself" tick as soon as they are done.

| Step | What to do |
|---|---|
| 1. Activate | Ticks itself. |
| 2. Choose your tender website | Select Tamil Nadu, GeM, or another website. |
| 3. Save your website login | **Enter the login**: type the login ID and password, then **Save changes**. Not needed for GeM. |
| 4. Install the DSC signer | **Install it** → **Install the DSC signer**; Windows asks for permission once. Not needed for GeM. |
| 5. Categories | **Review in Settings**: keep the website categories your kind of work appears in, then **I've checked them**. |
| 6. Intent words | Words for the work you bid for. The starting list is for software, website and e-learning work: use **Remove all** and type your own (several at once, separated by commas), **Save changes**, then **I've checked them**. |
| 7. Excluded words | Words that mean "not for us" (for example "civil works", "furniture"). Then **I've checked them**. |
| 8. Folder on this computer | Ticks itself (Documents\TenderAssist). |
| 9. Google Drive folder | **Name the folder**: type a name such as `Tenders 2026-27`, then **Save the folder name**. TenderAssist makes it in your My Drive. |

When all nine are ticked, the checklist goes away.

## 4. Your first search

1. Today → **Find tenders** → choose the website and the days (**Today**, **Yesterday**, **Last 3 days**…) → **Start**.
2. Tamil Nadu and other GePNIC websites: TenderAssist opens the website and fills in your login. **You type the CAPTCHA**, then, when asked, select **Launch DSC signer** and enter your **DSC PIN**. TenderAssist calls you (taskbar flash and sound) at both steps.
3. TenderAssist searches your categories, reads each tender and keeps the ones that match your words. When it is unsure about one, it asks **Keep or skip?** (2 minutes to answer; unanswered ones wait for you).
4. At the end, the **search report** shows how many were found, kept and rejected.

## 5. Decide

1. Select **Decide them now** (or Today → **Decide**). One tender at a time: what it is, its value, days left, and **why** it was kept.
2. **Approve** saves its documents and eligibility sheet, adds it to the day's report sheet, and uploads it to your Drive folder. **Reject** and **Later** do what they say. Keys: A, R, D.
3. Then check the tenders **your rules rejected**: **These are right** clears them all, or **Check one by one**.

## Where things are

- **On this computer:** Documents\TenderAssist\October-2026\12-10-2026\, with a folder per approved tender (documents and Eligibility.xlsx) and the day's report sheet (one per website, such as "Approved-Tenders-12-10-2026 - GeM.xlsx").
- **In Google Drive:** My Drive\<your folder>\, same layout. Settings → Folders → **Open in Drive**.
- **Tenders:** every tender, by status, with search and sort.
- **Runs:** every search, by date.
- **Reports:** per day, how many tenders the website published, how many were in your categories, and how many were shortlisted and approved.
